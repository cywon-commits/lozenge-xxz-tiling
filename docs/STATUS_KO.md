### 원인 후보

1. **(가장 유력) 99% 기준 + 이산 S^z 섹터 + 유한 온도.** 유한 계에서 결정의 큰 스핀 J = m_L N은 S^z = J, J−1, …로 양자화되어 있고,
   한 단위가 m/m_L을 1/J(3/5에서 2%, dice에서 1%)만큼 낮춘다. 99%에 닿으려면 S^z = J 섹터가 대부분이어야 하므로
   h가 마지막 준위 교차보다 약 T만큼 더 커야 한다. 이 편향은 x와 무관한 덧셈꼴(≈ 0.5–1.5 T)이라, h₋ 자체가 작은 Δ = 0.99에서 비율로 커진다.
   근거: (h₋ − 예측)·β가 0.5–1.5로 비슷하고, 3/5에서 β = 48 → 96일 때 차이가 0.018 → 0.009로 절반, N = 500 → 980에서 0.018 → 0.013으로 감소.
   반례: dice는 β = 96에서도 차이가 거의 줄지 않음(0.012 → 0.011).
2. **유한 크기에서의 양자 보정.** 2단계 식은 고전적인 Néel 벡터 회전(연속 각도)을 가정한다. J가 50–100인 클러스터에서는 각도 자유도가
   양자화되어 h₋ 근처가 1/J 정도로 둥글어진다. Δ = 0.99처럼 h₋가 작은 곳에서 상대적으로 크다.
3. **K 값.** `K_table`은 N ≈ 1000의 K_raw이고 1/11에서 크기 의존성이 크다(k = 3: 0.087, k = 5: 0.107). 다만 비율 1.6을 K로 설명하려면
   K가 약 2.5배여야 하고, Δ = 0.95에서 같은 K로 ±6% 일치하므로 가능성은 낮다.
4. **1차 섭동의 유효 범위(x ≪ x_c).** Δ = 0.99는 x_c(3/5: 0.10, dice: 0.23)보다 훨씬 작아 식이 가장 잘 맞아야 하는 영역이다. 원인일 가능성 낮음.
5. **코드 부호·규약.** Δ = 0.95, 0.97에서 일치하고 단위 테스트를 통과했으므로 가능성 낮음.
