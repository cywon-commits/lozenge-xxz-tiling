## 공통 정의

**해밀토니안** (S = 1/2, J = 1, 반강자성):

    H = Σ_<ij> [ Sx_i Sx_j + Sy_i Sy_j + Δ Sz_i Sz_j ] − h Σ_i (cos θ_h · Sz_i + sin θ_h · Sx_i)

- x ≡ Δ − 1. Δ > 1은 easy-axis(z), Δ < 1은 easy-plane. Zeeman 항은 −h·S이다(자화가 h 방향이면 에너지가 내려간다).
- m = |N_A − N_B|/(2N) (논문 I 규약). Lieb 모멘트 M = mN, M/M_dice = 6m.

**격자.** 논문 I Table I의 결정을 초격자의 k×k 복사본 토러스로 만든다: `src/structs.py`의 `load_cell(name, k)`.
이름은 `square, 1/11, 1/9, 1/7, 1/6, 1/5, 1/4, 1/3, 1/2, 3/5, 2/3, dice`. 주기 경계. `load_cell`이 bond 수 2N과 이분성을 확인한다.

**방법.** SSE directed loop, heat-bath 탈출 확률: `src/sse_xxz.py`. h ∥ z이면 모든 Δ에서 부호 문제가 없다.

**측정량** (사이트당, `sse_xxz.run`의 반환값, 각각 (평균, 오차)):

| 키 | 뜻 |
| --- | --- |
| `E` | 전체 에너지, Zeeman 포함 |
| `Exy` | −⟨n_offdiag⟩/(βN) = ⟨SxSx + SySy⟩ |
| `Ezz_from_E` | (E − Exy + h·m)/Δ = ⟨Σ SzSz⟩/N. 동시각 추정량 `Ezz`보다 오차가 2–3배 작으므로 이것을 쓴다 |
| `m` | ⟨Sz⟩ |

Hellmann–Feynman에 의해 ∂e/∂Δ = `Ezz_from_E`이다. 계단 기울기는 에너지 차이가 아니라 이 양의 차이로 구한다.

**오차.** 블록 20개 평균. 최종값은 독립 seed의 평균과 표준오차. 블록 길이가 적분 자기상관 시간의 20배 이상인지 A0에서 확인한다.

**평형화 판정.** (i) seed끼리 E가 2σ 안에서 일치, (ii) 측정 구간 앞 절반과 뒤 절반의 평균이 2σ 안에서 일치,
(iii) h ∥ z, Δ ≥ 1의 페리 결정에서 측정된 m이 Lieb 값과 10⁻⁴ 안에서 일치.

**출력.** 실행 하나에 JSON 한 줄(`scripts/s4_qmc.py`가 `.jsonl`에 추가). 작업 목록은 `data/stage4/jobs_*.txt`,
실행은 `scripts/run_jobs.sh <jobs> <workers>`, 표는 `scripts/s4_analyse.py`.

## A0. 준비: SSE 속도 수정과 기준 측정 (반드시 먼저)

문제: `sse_xxz.run`은 sweep당 루프 수를 nl = 2n/10으로 고정한다(n은 연산자 수). 간극이 없는 경우 루프 하나가 길어져 sweep 시간이 폭증한다.
세션에서 3/5 결정(N = 500, β = 24, Δ = 0.97)의 3000 sweep에 44분, 1/11 결정(N = 297, β = 60, Δ = 1)의 5800 sweep에 59분이 걸렸다.

1. `sweep`이 방문한 꼭짓점 수(루프 걸음 수의 합)를 함께 반환하게 한다.
2. 평형화 동안 nl을 조정해 sweep당 방문 꼭짓점 수가 2n 근처가 되게 하고(nl ← nl·2n/방문 수, 최소 1), 측정 동안은 고정한다.
3. `tests/test_sse_xxz.py`가 그대로 통과하는지 확인한다(15개 조건, 4σ 이내).
4. Δ = 1 재현: square(k = 8, β = 24, h = 0)의 E = −0.6694(2) 근처(유한 크기 포함 ±0.001), 3/5 결정(k = 8, β = 36, h = 0.20)의 Exy = −0.31337(8), Ezz = −0.34237(8).
5. 기준 측정: 3/5 결정 k = 5, Δ = 0.97, h = 0.10, β = 24에서 sweep당 시간과 E, m의 적분 자기상관 시간을 잰다. m/m_Lieb = 0.870(1)이 재현되어야 한다.
6. 실행 JSON에 커밋 해시(`git rev-parse --short HEAD`)를 기록하게 한다.

산출: `docs/benchmark.md`에 수정 전후의 sweep당 시간, 자기상관 시간, 재현값. 이 수치로 A1–A3의 nmeas를 정한다.

## A1. Easy-plane, h ∥ z의 m(h)와 E(h) (어려운 방향) — 최우선

- 구조: square, 1/11, 1/5, 1/3, 1/2, 3/5, dice. 크기 두 가지: N ≈ 500과 N ≈ 1000.
- Δ = 0.99, 0.97, 0.95. h = 0.02 ~ 0.40J, 간격 0.02J.
- β = 24와 48에서 Δ = 0.97, 3/5 결정으로 β 수렴을 먼저 본다. 차이가 오차 안이면 β = 24로 전부 돌린다.
- seed 2개. 목표 오차: m은 Lieb 값의 0.5%, E는 2×10⁻⁴.
- 산출:
  - 구조별 m(h) 표와 그림. 2단계 식(P-c)을 같은 축에 선으로 그린다. K는 `K_table.json`, χ는 0.065/J와 0.125/J 두 경우.
  - h₋: m이 Lieb 값의 99%에 처음 닿는 자기장. h₋·m/(2|x|)를 K와 비교한다.
  - 각 h에서 E가 가장 낮은 구조와 전이 자기장. 두 크기에서 같은지 확인한다.
- 판정: P-c (h₋가 예측의 ±20% 안), P-d (Δ = 0.97, 0.95에서 square 다음이 3/5인지 1/3인지).
- 주의: square의 유한 크기 보정이 가장 크다. 구조마다 N이 다르므로 전이 자기장은 두 크기의 차이를 계통 오차로 적는다.

## A2. Easy-axis 정밀 측정 (h ∥ z, Δ > 1)

- 구조: Table I 결정 12개와 square. N ≈ 1000 (k는 논문 I Table I과 같게).
- Δ = 1.02, 1.05, 1.10, 1.25. β = 36 (Δ = 1.02), 24 (그 외). h는 논문 I이 각 결정에 쓴 값, square는 h = 0.
- seed 3개. 목표 오차: `Ezz_from_E` 1×10⁻⁴, `E` 1×10⁻⁴.
- 산출:
  - e_∥(Δ) 표와 계단 기울기 ΔEzz/Δm. Square와 각 결정에 a − b√x 맞춤.
  - 각 Δ에서 e₀ = E + h·m의 볼록 껍질과 계단 자기장. 논문 I의 `stair_boot.py` 방식으로 4000회 재표본해 꼭짓점 존재 확률.
- 판정: P-a, P-g. 3단계에서 나온 새 꼭짓점 후보(1/2, 2/3, 1/6)의 존재 확률이 0.9를 넘는지.

## A3. K의 크기 의존성 (Δ = 1)

- 1/11, 1/9 결정: k = 3, 4, 5, 6, 7, 8. β = 60, h는 논문 I이 각 결정에 쓴 값 (1/11은 0.07J).
- Square spin-flop: L = 24, 36, 48, h = 0.10, 0.15, 0.20, β = L.
- 산출: K_측정 = (E + h·m − 3·Ezz_from_E)/2 대 1/J. K_∞와 a의 맞춤값. Square의 K_sq(h → 0, L → ∞).
- 판정: P-e. 시작 자기장 기울기(Δ → 1 극한)의 불확실성 −0.3 ~ −0.8을 ±0.1로 줄인다.
- 주의: βh가 작으면 다중항의 S^z = M − 1 성분이 섞인다. m/m_Lieb < 0.998인 실행은 β를 올려 다시 한다.

## A4. 가로 자기장 SSE (h ⊥ z) — 새 코드

- 자기장 축을 양자화 축으로 돌리면 H = Σ[Sz'Sz' + ((1+Δ)/4)(S⁺S⁻ + h.c.) + ((Δ−1)/4)(S⁺S⁺ + h.c.)] − hΣSz'.
  쌍 생성·소멸 꼭짓점이 추가된다. 주기 배치에서 쌍 연산자 수가 항상 짝수이므로 Δ < 1에서도 부호 문제가 없을 것으로 본다 [추측].
- 구현 전에 4-사이트, 6-사이트 고리에서 유한 온도 정확해와 비교한다. 부호 문제가 있으면 구현을 멈추고 보고한다.
- 단위 테스트: `scripts/s3_ed_hx.py`의 dice N = 12 값(`data/stage3/ed_hx.json`)을 재현.
- 계산: 3/5 결정과 dice, N ≈ 500. Δ = 1.05 (Z₂ 전이)와 Δ = 0.95 (준플라투). h = 0.05 ~ 0.40J.
- 산출: m_x(h), ⟨|m_z|⟩와 Binder 비, 준플라투의 기울기.
- 판정: P-f, P-h.

## A5. 전체 구조에 대한 XXZ 스핀파 껍질

- 논문 I의 `code/bloch_lswt.py`를 복사해 두 가지를 추가한다: Néel ∥ z는 eig[(ΔD − A)(ΔD + A)], Néel ⊥ z는 eig[(D − A)(D + ΔA)].
- 대상: 논문 I의 hub-free 4510개 구조와 hub 포함 후보(`data/k1/`). Δ = 0, 0.5, 0.9, 1, 1.1, 1.5, 2, 4.
- 산출: Δ별 껍질 꼭짓점. Table I 밖의 구조가 꼭짓점이 되는지.
- 단위 테스트: Δ = 1에서 논문 I의 Bloch 값과 10⁻⁶ 이내, `data/stage3/lswt_xxz.json`(유한 클러스터)과 10⁻⁴ 이내.
- 주의: 스핀파는 같은 가지 안의 구조 비교에만 쓴다. 두 가지 사이의 비교(K)는 S = 1/2에서 부호가 틀린다(K = 2S² − 1.337S).
