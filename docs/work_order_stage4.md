## 0. 공통 정의

**해밀토니안.** S = 1/2, J = 1.

    H = Σ_<ij> [ Sx_i Sx_j + Sy_i Sy_j + Δ Sz_i Sz_j ] − h Σ_i (cos θ_h · Sz_i + sin θ_h · Sx_i)

- 반강자성 J > 0. 자기장은 Zeeman 항 −h·S로 들어간다(자화가 h와 같은 방향이면 에너지가 내려간다).
- x ≡ Δ − 1. Δ > 1은 easy-axis(z), Δ < 1은 easy-plane.
- m = |N_A − N_B|/(2N) (논문 I의 규약). Lieb 모멘트 M = mN. M/M_dice = 6m.

**격자.** 논문 I의 Table I 결정을 초격자 (p, q, s)의 k×k 복사본 토러스로 만든다(`src/structs.py: load_cell(name, k)`).
이름은 `'square', '1/11', '1/9', '1/7', '1/6', '1/5', '1/4', '1/3', '1/2', '3/5', '2/3', 'dice'`.
주기 경계. 모든 그래프는 이분 그래프이고 bond 수는 2N이다(`load_cell`이 확인한다).

**방법.** SSE directed loop, heat-bath 탈출 확률 (`src/sse_xxz.py`). 이분 그래프에서 모든 Δ와 h ∥ z에 대해 부호 문제가 없다.
선택 이유: 논문 I의 검증된 코드에서 대각 가중치만 바꾼 것이라 Δ = 1에서 기존 결과와 직접 비교된다.

**측정량** (사이트당, `sse_xxz.run`의 반환값):

- `E`: 전체 에너지(Zeeman 포함). `Exy` = −⟨n_offdiag⟩/(βN) = J⟨SxSx + SySy⟩. `m` = ⟨Sz⟩.
- `Ezz_from_E` = (E − Exy + h·m)/Δ = J⟨Σ SzSz⟩/N. 동시각 추정량 `Ezz`보다 오차가 2–3배 작으므로 이것을 쓴다.
- Hellmann–Feynman: ∂e/∂Δ = Ezz. 에너지 차이 대신 이 양을 재면 계단 기울기를 큰 수의 뺄셈 없이 얻는다.

**오차.** 20개 블록 평균. 블록 길이가 적분 자기상관 시간의 20배 이상인지 확인한다. 최종값은 독립 seed 3개의 평균과 표준오차.

**출력.** 실행 하나에 JSON 한 줄(`scripts/s4_qmc.py`가 `.jsonl`에 추가). 매개변수, seed, 실행 시간, 커밋 해시를 함께 적는다
(커밋 해시 기록은 아직 없다. W1에서 추가할 것).

**단위 테스트.** `python tests/test_sse_xxz.py`가 통과해야 한다(N = 12 클러스터 3개 × (Δ, h, β) 5조합, 유한 온도 정확해와 4σ 이내).
SSE 코드를 고칠 때마다 다시 돌린다. 추가로 Δ = 1에서 논문 I의 값을 재현해야 한다:
square e₀ = −0.66944(1), 3/5 결정(k = 8, β = 36, h = 0.20) Exy = −0.31337(8), Ezz = −0.34237(8).

**평형화 판정.** 서로 다른 seed의 E가 오차 안에서 일치하고, 앞 절반과 뒤 절반의 블록 평균이 2σ 안에서 같을 것.
페리 결정에서는 측정된 m이 Lieb 값과 10⁻⁴ 안에서 같을 것(h ∥ z, Δ ≥ 1).

## 2. 작업

### W1. Easy-axis 정밀 측정 (h ∥ z, Δ > 1)

- 구조: Table I의 12개 결정과 square. 크기는 N ≈ 1000 (k는 논문 I Table I과 같게).
- Δ = 1.02, 1.05, 1.10, 1.25. β = 36 (Δ = 1.02), 24 (그 외). h는 각 결정의 플라투 안: 논문 I의 값 그대로. Square는 h = 0.
- ntherm = 2000, nmeas = 20000, seed 3개. 목표 오차: Ezz_from_E 1×10⁻⁴, E 1×10⁻⁴.
- 산출: (i) Ezz(Δ) 표와 계단 기울기 ΔEzz/Δm, (ii) Δ = 1에서 Δ까지 Ezz를 적분한 에너지와 직접 측정한 E의 비교,
  (iii) 각 Δ에서 e_T − h·m의 볼록 껍질과 계단 자기장, 논문 I의 `stair_boot.py` 방식 재표본 4000회로 꼭짓점 존재 확률.
- 판정: P-a, P-b. 3단계에서 나온 새 꼭짓점 후보(1/2, 2/3, 1/6)의 존재 확률.
- 세션에서 이미 한 것: Δ = 1.02, 1.05, 1.10에서 6개 구조, seed 1개 (`data/stage4/ezz_easy_axis.jsonl`).

### W2. Easy-plane, h ∥ z의 m(h) 곡선 (어려운 방향)

- 구조: square, 1/11, 1/5, 1/3, 1/2, 3/5, dice. 두 크기(N ≈ 500, 1000).
- Δ = 0.99, 0.97, 0.95. h = 0.02 ~ 0.40J, 간격 0.02J. β = 36과 72(평면 질서는 간극이 없으므로 β 수렴을 확인).
- ntherm = 2000, nmeas = 10000, seed 2개.
- 산출: 구조별 m(h), E(h). 각 h에서 E가 가장 낮은 구조 → 전이 자기장. 플라투 시작 h₋(m이 Lieb 값의 99%에 닿는 자기장).
- 판정: P-c, P-d. h₋·m/(2|x|)가 3단계 K 표와 맞는지.
- 주의: 같은 N이 아닌 구조끼리 E를 비교하므로 두 크기에서 전이 자기장이 같은지 확인한다. Square의 유한 크기 보정이 가장 크다.
- 세션에서 이미 한 것: Δ = 0.97, h = 0.10J에서 3/5 결정과 dice 두 점뿐이다 (`data/stage4/mh_easy_plane_hz.jsonl`).
  3/5: m_z/m = 0.870(1), dice: 0.978(1). 예측(3/5는 h₋ ≈ 0.11–0.13J 아래라 기울어짐, dice는 h₋ ≈ 0.085J 위)과 맞는다.
- **속도 문제.** Easy-plane에서는 간극이 없어 루프가 길다. 3/5 결정(N = 500, β = 24)의 3000 sweep에 44분이 걸렸고,
  square와 1/3 결정은 2시간 안에 한 점도 끝나지 않았다. `sse_xxz.run`의 루프 수 규칙(nl = 2n/10)을 '방문한 꼭짓점 수가 2n이 되도록'
  으로 바꾸고, sweep당 시간을 먼저 재서 작업량을 정할 것. Δ = 1의 β = 60 실행(W3)도 같은 이유로 느리다(N = 297에서 5800 sweep에 59분).

### W3. K의 크기 의존성 (Δ = 1)

- 1/11, 1/9 결정: k = 3 ~ 8, β = 60, h = 0.07. Square spin-flop: L = 24, 36, 48, h = 0.10, 0.15, 0.20, β = L.
- 산출: K_측정(J) 대 1/J. 강체 회전자 인자 P_J = J(2J−1)/((J+1)(2J+3))와 비교. Square의 K_sq(h → 0, L → ∞).
- 판정: P-e. 시작 자기장 기울기의 불확실성(−0.3 ~ −0.8)을 ±0.1로 줄이는 것이 목표.

### W4. 가로 자기장 SSE (h ⊥ z) — 새 코드

- 자기장 축을 양자화 축으로 돌리면 H = Σ[Sz'Sz' + ((1+Δ)/4)(S⁺S⁻ + h.c.) + ((Δ−1)/4)(S⁺S⁺ + h.c.)] − hΣSz'.
  쌍 생성·소멸 꼭짓점이 추가된다. 부격자 회전 후 쌍 연산자의 부호는 Δ < 1에서 음이지만, 주기 배치에서 쌍 연산자 수가 항상 짝수라
  부호 문제가 없을 것으로 본다 [추측]. 구현 전에 4-사이트, 6-사이트 정확해로 확인한다.
- 구조: 3/5 결정과 dice, N ≈ 500. Δ = 1.05 (h ⊥ z, Z₂ 전이)와 Δ = 0.95 (평면 내 자기장, 준플라투).
- 산출: m_x(h), ⟨|m_z|⟩와 Binder 비(Z₂ 질서 변수), 준플라투의 기울기.
- 판정: P-f. 준플라투 기울기가 0.03–0.04·x²/J 수준인지(3단계 ED 외삽).
- 단위 테스트: `scripts/s3_ed_hx.py`의 dice N = 12 값을 재현.

### W5. 전체 구조에 대한 XXZ 스핀파 껍질

- 논문 I의 `bloch_lswt.py`에 두 가지를 추가: Néel ∥ z는 eig[(ΔD − A)(ΔD + A)], Néel ⊥ z는 eig[(D − A)(D + ΔA)] (Bloch 형태).
- 대상: 논문 I의 hub-free 4510개 구조와 hub 포함 후보(`data/k1/`의 목록). Δ = 0, 0.5, 0.9, 1, 1.1, 1.5, 2, 4.
- 산출: Δ별 껍질 꼭짓점. Table I 밖의 구조가 꼭짓점이 되는지.
- 주의: 스핀파는 같은 가지 안의 구조 비교에만 쓴다. 두 가지 사이의 비교(K)는 S = 1/2에서 부호가 틀린다(K_LSWT = 2S² − 1.337S).
- 단위 테스트: Δ = 1에서 논문 I의 `data/paper/bloch_lswt.json` 값과 10⁻⁶ 이내로 일치. `scripts/s3_lswt.py`의 유한 클러스터 값과 10⁻⁴ 이내.
